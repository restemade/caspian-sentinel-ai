# Delivery plan

## P0 - submission blocker

- PWA capture flow with location and consent
- image-quality validation and OpenCV evidence overlay
- Gemini Vision classification with strict schema and safe fallback
- human review before an incident becomes actionable
- GIS incident map
- volunteer ticket lifecycle and before/after evidence
- persistent PostgreSQL storage and audit trail
- Docker Compose, health checks and reproducible README
- automated backend and frontend smoke tests
- public deployment on a new port without touching the pre-hackathon prototype

## P1 - only after P0 passes end-to-end

- lightweight floating-station 3D digital twin
- optional IoT telemetry source
- presentation storytelling and advanced analytics
- offline upload queue and multilingual UI

## Definition of done

A jury member can capture or upload a pollution photograph, inspect the evidence overlay and AI reasoning, approve the incident, see it on the map, assign a cleanup ticket, upload after-evidence and close the ticket in under five minutes.
